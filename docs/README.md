# svarg: документация C++ бэкенда

svarg генерирует из OpenAPI спецификаций C++ типы, сервер и клиентов поверх hidi (HTTP/2). Сгенерированный код —
это данные (типы, описания полей, медиа типы), вся логика (де)сериализации и маршрутизации — в рантайме
`include/svarg/backend/cxx/support/`.

Разделы:

- [Генерация](generation.md) — запуск и опции svarg, сгенерированные файлы, CMake, большие спеки, ошибки
- [Схемы и типы](schemas.md) — null, обязательные и лишние свойства, anyOf/oneOf и дискриминатор,
  перечисления, имена
- [Сервер и маршрутизация](server.md) — операции спеки, свои маршруты, порядок выбора маршрута
- [Тела и кодеки](codecs.md) — форматы тел, свой медиа тип через `media_codec`
- [Клиент и ответы потоком](client.md) — `send`, транспорт и middleware, потоковые медиа типы

Будут дополнены: параметры (style/explode), multipart, ограничения.
